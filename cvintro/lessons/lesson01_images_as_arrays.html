Lesson 1: Images as Arrays¶

A digital image is just a grid of numbers. In this lesson we build a small image from scratch with NumPy, look at how grayscale and color images are represented, and display them with Matplotlib.

In [1]:
import numpy as np
import matplotlib.pyplot as plt

A grayscale image is a 2D array¶

Each entry is a pixel intensity. For an 8-bit image, values range from 0 (black) to 255 (white).

In [2]:
gray = np.zeros((100, 100), dtype=np.uint8)
gray[20:80, 20:80] = 255   # a white square on a black background

print('shape:', gray.shape, 'dtype:', gray.dtype)

plt.imshow(gray, cmap='gray', vmin=0, vmax=255)
plt.title('Grayscale image (100x100)')
plt.axis('off')
plt.show()

shape: (100, 100) dtype: uint8

A color image is a 3D array¶

The third dimension holds the red, green, and blue channels, so the shape is (height, width, 3).

In [3]:
color = np.zeros((100, 100, 3), dtype=np.uint8)
color[:, :, 0] = 255        # red channel on for the whole image
color[20:80, 20:80, 1] = 255  # add green in the middle square -> looks yellow

print('shape:', color.shape, 'dtype:', color.dtype)

plt.imshow(color)
plt.title('Color image (100x100x3)')
plt.axis('off')
plt.show()

shape: (100, 100, 3) dtype: uint8

Simple pixel-level operations¶

Because an image is just an array, standard NumPy operations apply directly, e.g. inverting intensities.

In [4]:
inverted = 255 - gray

fig, axes = plt.subplots(1, 2, figsize=(6, 3))
axes[0].imshow(gray, cmap='gray', vmin=0, vmax=255)
axes[0].set_title('Original')
axes[0].axis('off')
axes[1].imshow(inverted, cmap='gray', vmin=0, vmax=255)
axes[1].set_title('Inverted (255 - pixel)')
axes[1].axis('off')
plt.tight_layout()
plt.show()
